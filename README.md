## English lexicon 0.2.1

**Changes from 0.2.0.** The word list is identical (139,492 words; the `words` member is byte for byte the same). Only the manifest changed: `version` is 0.2.1 and `attribution` now also names CEFR-J and Octanove, the two sources behind the short-word rule, each with its license. 0.2.0 listed Wiktionary only.

**What it is for.** When a player fills in a word that is not the answer, the game checks this list:
- **Real word:** the entry counts as a wrong guess.
- **Not a real word:** it counts as a typo, which costs less.

**Contents.** 139,492 words, 3–15 letters, upper-case A–Z only.

**Format.** JSON with two members:
- `manifest`: language, version, filter, count, license and attribution.
- `words`: maps each word length to one string in which all words of that length are concatenated in sorted order, with no separator. Every word in a bucket has the same width, so a reader can binary-search the string directly.

**How it was built.**
- **Source:** the English Wiktionary dump from kaikki.org (2026-10-03).
- **Entries kept:** entries that have a translation table, together with their inflected forms.
- **Entries removed:**
  - proper nouns, abbreviations, affixes and phrases;
  - entries whose every sense is obsolete, archaic, rare, dialectal or a misspelling;
  - all-caps or dotted surface forms, and words without a vowel.
- **Short words:** 3- and 4-letter words are kept only if they are CEFR headwords (CEFR-J 1.6 A1–B2, Octanove C1/C2) or one of their inflections. The list records membership only; it contains no CEFR levels.
- **Answers:** every answer in the game's puzzle pool is included.
- **Normalisation:** words are converted to the grid alphabet (accents removed, upper case).

The data was generated by the game's content pipeline (`scripts/export_lexicon.py`).
